CHROMA — Acode Edition
A phone-friendly colour playground made with plain HTML, CSS, and JavaScript. No React, Vite, npm, or package installation required..

Files:
- index.html: page structure
- style.css: styling and responsive layout
- script.js: features and interactions

Saved palettes, history, theme and score use browser localStorage. Image extraction runs locally in your browser. Clipboard support depends on the browser preview.
